# Sujeet Kumar — Portfolio

Personal portfolio website showcasing my education, experience, projects, technical skills, achievements, and contact information.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Dark / light theme toggle
- Mobile navigation menu
- Experience tabs
- Project category filters
- Scroll-based reveal animations
- Cursor glow interaction
- Contact form UI
- Responsive project, skills, and achievement cards

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts — Inter & JetBrains Mono

## 🚀 Run Locally

No build system is required.

### Option 1 — Open directly

Open `index.html` in a browser.

### Option 2 — VS Code Live Server

Open the project in VS Code and run `index.html` with Live Server.

### Option 3 — Python HTTP server

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
